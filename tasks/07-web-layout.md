# 07 — Web: layout, trees, sources

**Goal:** app shell with left panel working end to end.

## Scope
- Three-column layout: left panel, graph area (placeholder), chat area (placeholder)
- Tree list, create tree, select tree
- Tree settings: edit title and instructions (saves via `PATCH`)
- Sources: list, upload `.md`/`.txt`, delete, open in a viewer
- Selected tree and node kept in the URL (reload keeps state)
